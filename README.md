# 🤖 Dhiww Cyber Toolkit Bot

Bot Telegram berisi tools cyber untuk belajar & riset.

## ✨ Fitur
- 🔐 Hash Generator (MD5, SHA1, SHA256, SHA512)
- 🔑 Password Generator + Checker
- 🔢 Base64 Encode/Decode
- 🎨 QR Code Generator
- 🌐 IP Intelligence (lokasi, ISP, proxy detection)
- 🔍 DNS Lookup (A, AAAA, MX, NS, TXT, CNAME)
- 🔗 URL Parser

## 🚀 Cara Pakai
1. Clone repo ini
2. `npm install`
3. Bikin file `.env` isi `TELEGRAM_TOKEN` & `OWNER_ID`
4. `node bot.js`
